    Projects

    eVibe cards

    This project introduces a website where you can create or view a digital, custom-made postcard, referred to as an eVibe card. The eVibe card is designed to reflect the individual vibe of the person it's created for. When creating an eVibe, you select three questions and a picture. This generates a code which the intended person can use to visit the website, answer the selected questions, and create their personalized eVibe with their responses and the chosen picture.
